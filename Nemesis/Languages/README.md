# Nemesis translations

English C# strings (letters, settings, dialogs, taunts) live in `Languages/English/Keyed/Nemesis.xml`.

**Shipped:** `ChineseSimplified` and `Russian` Keyed packs mirror English tag-for-tag.

Translators: copy the English file into a new language folder and translate **values**, keeping **tag names** unchanged. Placeholders `{0}`, `{1}`, `{2}` must remain.

```
Nemesis/
  Languages/
    Russian/
      Keyed/
        Nemesis.xml
```

Package id: `AzraelGodKing.Nemesis`
