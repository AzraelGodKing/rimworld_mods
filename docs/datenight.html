Date Night

Schedule romance. Make memories.

Steam Workshop Download zip

Overview

Adds a Lovin timetable slot to the Schedule tab. Paint Lovin on both partners for the same hours — each colonist goes to bed and waits. When both share a double bed, lovin uses a short mean-time-between (like the vanilla Always Do Lovin debug option) until the schedule changes.

Dependencies: requires Harmony. Load Date Night after it.
Save-safe: safe to add mid-save. Before removing, clear Lovin slots back to Sleep / Anything.

How it works

1. Paint Lovin

Open Schedule and pick the new rose Lovin button (drawn next to Sleep / Meditate — vanilla hardcodes that grid, so XML alone never shows a custom slot).

2. Both partners

Assign the same hours on both lovers. Each paths independently to a shared rendezvous double bed (not their private singles).

3. Shared double bed

Vanilla partner-in-bed rules

When both are in the double, lovin chance uses a short MTB for the rest of the window. Missing partner or only a single bed: they wait; no lovin.

4. Needs first

Hungry, chemical desire, player-forced jobs, and exhaustion block bed-forcing so colonists eat (etc.) before the date.

Settings

Pregnancy-safe cooldown

Default ON

Only shortens lovin chance while scheduled; keeps vanilla post-lovin cooldown so pregnancy rolls stay sane.

Eager mode

Optional

Also shortens post-lovin cooldown like Always Do Lovin. Can spam pregnancy rolls — leave off unless you want that.

Requirements checklist

  • Love relationship between the pair
  • Both scheduled Lovin for the window
  • A reachable shared double bed (rendezvous cache picks one; no ownership storm)
  • Works for no-sleep / low-rest pawns who never hit a Sleep block

Dev tools

With Dev mode on: Date Night menu — make selected pair lovers, click-to-pair, paint Lovin all day, force lovin now, log rendezvous bed.

Installation

  1. Download the zip above (or copy the DateNight folder into your RimWorld Mods directory).
  2. Enable Harmony, then Date Night, and restart.
  3. Open a colonist’s Schedule tab — Lovin appears beside Sleep.
