### Changed
- **G8 round 2: raw 1:1 on any host map size (fixes stairs unlinked from the landed pad)** — landing on a map whose size differs from the pocket (e.g. a Geological Landforms tile) split the systems: cargo/vanilla place at raw coordinates while paint/projection/realign used proportional scaling, recreating two circles and yanking the landing off the pad on load. All gravship pocket↔host cell mapping is now raw 1:1 (substructure projection, deck/roof paint, deck-under-buildings restore, wired-shaft ownership, load-time landing realign). New hard invariant after every land and forced sync: each pocket landing sits at exactly its host shaft's cell (`SnapAllLandingsUnderShafts`), with wiring preserved via `currentlyGeneratingPortal`. Pocket-side things (landings) found inside the packed vanilla ship are stripped before placement — kills the "already spawned" error and cross-map teleports. Ghost-pad cleanup now clears in 4096-cell batches instead of skipping when over the old 2048 cap (8k+ leftover cells from earlier broken lands finally drain). Build stamp `g8-raw11-landing-snap-v2`.
- **Launch lag round 2** — cached the `WorldComponent_StrataGravshipStacks` and projected-substructure map-component lookups (both were linear scans on per-cell paths), reordered `IsOnboardGravship` to answer host-deck cells with one cached set lookup before any pocket sweep, and moved the per-cell shaft-rect scan behind the cheap grid checks in `IsLinkedDeckCell`.
- **G8 Rotation-aware gravship deck cargo (fixes the "two circles" land bug)** — packed A+/B+ contents now land with the exact vanilla transform (`root + PrefabUtility.GetAdjustedLocalPosition(local, gravship.Rotation)`, rotations rotated like `Gravship.GetPlacementValues`). G7 ignored the landing rotation the player picked, so the repainted footprint + restored shafts landed rotated (correct circle) while furniture landed unrotated (offset circle). Cargo now also moves pocket landings and pawns with the same transform, carries player-visible deck terrain/roofs, remaps zones + cell designations, clears the abandoned old-footprint floor, and re-anchors a drifted room under its shaft at capture so old misalignment self-heals on the next flight. Build stamp `g8-rot-cargo-v1`.
- **Launch stall fixed (cached stack lookups)** — `IsOnboardGravship` / `ValidSubstructureAt` / `InsideFootprint` patches ran all-maps × all-portals scans per cell; vanilla calls them in region sweeps during launch (`JobGiver_BoardOrLeaveGravship`, substructure overlay, gravship mask regen), turning "Launch" → takeoff into a hard crawl. Engine-on-map, portal-host, and stack-root lookups are now cached (60-tick TTL + invalidation on any stack topology change). No worker thread needed — RimWorld map state is main-thread only; the scans were the cost, not the packing. Build stamp `g8-launch-cache-v1`.
- **Gravship level cap ±1** — ship stacks are hard-capped at one underdeck and one tower deck (new digs/towers from a gravship-linked floor are blocked; colony floors keep the normal ±2/Unlimited rules). Deeper ship stacks multiplied takeoff/land work and were the fragile path in travel bugs. Existing deeper stacks keep working. Build stamp `g8-ship-cap-pm1-v1`.
