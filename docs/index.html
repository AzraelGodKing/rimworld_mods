Installation

  1. Download the mod(s) using the buttons above.
  2. Extract the zip — it contains a single Homesteader or Stormproof folder — into your RimWorld Mods folder.
  3. Enable the mod(s) in the in-game mod list and restart.
  4. Stormproof requires the Harmony mod.
Save compatibility: safe to add mid-save. Before removing a mod, deconstruct its buildings and use up its items first.
