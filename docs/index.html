Installation

  1. Subscribe on Steam Workshop or download the zip from Downloads.
  2. For zips: extract into your RimWorld Mods folder — each archive is one mod folder.
  3. Enable Harmony, then the mod(s), and restart.
Save compatibility: safe to add mid-save. Before removing a mod, deconstruct its buildings or resolve active systems (for example an active Nemesis hunt) first.
