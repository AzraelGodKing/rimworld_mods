Installation

  1. Download the mod(s) using the buttons above (or subscribe on Steam Workshop).
  2. Extract the zip into your RimWorld Mods folder — each zip contains one mod folder.
  3. Enable the mod(s) in the in-game mod list and restart.
  4. These mods require the Harmony mod.
Save compatibility: safe to add mid-save. Before removing a mod, deconstruct its buildings / resolve active systems (e.g. an active Nemesis hunt) first.
