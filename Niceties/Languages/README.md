# Niceties translations

English keyed strings ship in `English/Keyed/Niceties.xml` (settings, inspect lines, hunt fail reason).

This mod has no DefInjected packs (no new buildings or research).

## Add a language (example: Russian)

```
Niceties/
  Languages/
    Russian/
      Keyed/
        Niceties.xml
```

Copy `English/Keyed/Niceties.xml`, translate values, keep tag names and `{0}` placeholders.

Package id: `AzraelGodKing.Niceties`
