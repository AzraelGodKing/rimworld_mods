# Workshop replies — mountain dig + tall towers

From [Strata comments](https://steamcommunity.com/sharedfiles/filedetails/?id=3762844292).

## @rats gaming (empty dig under mountain)

> That wasn't intentional — dig-under-mountain should give you rock to mine. When **Biomes! Caverns** is loaded it owns the underground layout, and on mountain / landform tiles that can leave a hollow contour with almost no ore. Next build detects sparse Biomes layouts (including “edge rock but empty under the mountain footprint”) and falls back to Strata's own rock fill so B1 stays diggable. Tower A+ over mountain / thick rock also gets mineable rock now instead of empty roof deck. Existing empty floors won't retro-fill — you'd need a new dig / new tower level. If you still see it after the update, say whether Biomes! Caverns (and Geological Landforms) are in the list.

---

## @Vardath (Monolyn / tall towers + sky)

> Tall towers from other mods still get normal sky above them. Strata doesn't create or steal a sky floor for those buildings. The roof deck (A+) is a separate pocket map that only opens when you build a **Strata tower stairwell or elevator**. Until then, surface buildings (Monolyn towers included) behave like vanilla under open sky. Don't run Strata with AASB or MultiFloors — those are competing multi-floor stacks, not the same as decorative tall buildings.
