AASB-inspired polish (parked)

Ideas from comparing Strata to As above, So below. Steal polish, not the 3-level hard cap. Do not run Strata alongside AASB or MultiFloors.

High value

  1. Live see-through roof view — From A+/sky decks, render the surface through open roof holes (live pawns, weather, water).
  2. Mental breaks that cross stairs — Binges find other-level stash; berserkers chase victims through shafts.
  3. Raider divert polish — Tighten existing raid pursuit so fights don’t die on the wrong floor.
  4. Vertical utilities as one net — Shaft junctions feel tankless/battery-free where the host net allows (DBH/VTE especially).
  5. Per-system kill-switches — Auto-disable haul relay / atmosphere / shaft fluid / robot soft-compat on repeated errors (beyond the master performance kill-switch).

Medium value

  1. Hospitality / guest / trader pathing across levels.
  2. Vehicle Framework soft-compat (roof-deck park/land rules).
  3. Modder API — reachable levels, first stair step, register vertical link, underground incident policy.
  4. Depth dim / mood slider for looking down from upper decks.
Explicitly not copying: hard cap at 1 up + 1 down; flat 12°C basement instead of geothermal + atmosphere. Optional later: a “shallow colony” settings preset (max ±1) without gutting deep play.

MultiFloors-inspired (parked)

Steal reliability and UX ideas — especially for Odyssey gravship linking. Do not adopt Prepatcher or MultiFloors’ amplifier as a hard dependency model without rewriting Strata’s pocket-stack follow.

Gravship — priority (linking pain)

  1. Explicit travel entitlement (Amplifier-like) — Gate which floors/cells follow launch with a clear host-side building or shaft flag, instead of only “any IStrataGravshipPortal pocket”. Reduces orphan ambiguity and GravAnchor leftovers.
  2. Ship ladder as grav-extender spine — Gravship shaft/elevator should expand / own vertical substructure range the way MultiFloors ladders act as extenders, so A+/B+ placement is not only projected silhouette + Harmony.
  3. Stable shaft identity across land — Persist a stack GUID + per-shaft ID (not just pocketMapId heuristics) so land never spawns a second “New” underdeck when packed stairs replace temp shafts.
  4. Substructure-ready gate before paint/rewire — Never CompleteLanding footprint rebuild until host ValidSubstructure (or VGE foundation proxy) is non-empty; single deferred sync path, not multi-hook races.
  5. One engine of record — Pin travelling stack to the packed ship’s engine thingID at takeoff; never PreferBestEngine / CurrentMap fallback during land rebind.
  6. Multi-shaft wiring table — Snapshot engine-relative offset → pocketMapId → under/tower for every host shaft; restore by table, not “first matching type wins”.

General MultiFloors UX worth stealing

  • Per-level work-type toggles (turn off hauling on a floor).
  • Medical bed preference across levels (already partly there — finish).
  • Reinstall buildings across levels.
  • Upper-level top-down / see-through renderer (overlaps AASB #1).
  • Float-menu / caravan selection that sees other levels (MultiFloors’ stated gaps — beat them).
Do not copy blindly: Prepatcher requirement; “everything on upper substructure in amplifier range packs as cargo” without a migration plan from pocket maps; no-cross-level-combat as a permanent Strata limit.
